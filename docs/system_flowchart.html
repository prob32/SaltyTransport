Salty Transport System Flowchart

Effective Surplus Model — Monthly 2-Phase Cycle

Model (monthly, affects depot modifiers)
Tooltip only (on-demand, display only)
Phase B: Bellman-Ford + WAS/WAD + Market Price Days 8–20

B1: Bellman-Ford Infrastructure Friction Model stl_distance_cache.txt

Runs once per origin state. Computes shortest-path friction to all reachable partners.

friction_per_state = max(1, 5 × infra_usage / infra) stl_bf_dist = cumulative friction along shortest path stl_pw = max(0, 100 − stl_bf_dist) // proximity weight

BF distances are transient — computed fresh, used, then cleaned up.

B2: Accumulate WAS/WAD + Market Price Sums Model stl_phase_b_generated.txt

For each partner × each good, reads raw buy_orders, sell_orders, production from game state. Computes effective_surplus and accumulates gravity-weighted values.

// Source price from partner's buy/sell ratio source_price = BASE × (1 + 0.75 × clamp((buy − sell) / min(buy, sell), ±1)) // Production-weighted market price sums wavg_psum += partner_production × source_price wavg_wsum += partner_production // Effective surplus (using LAST month's market_price) eff_surp = max(buy, sell) × (market_price − source_price) / market_price // If eff_surp > 0: partner is CHEAP → WAS (import supply) WAS += eff_surp × pw max_WAS += eff_surp × 100 // If eff_surp < 0: partner is EXPENSIVE → WAD (export demand) WAD += |eff_surp| × pw max_WAD += |eff_surp| × 100

No anti-oscillation subtraction — price mechanism + EMA smoothing provides natural damping.

B3: Finalize Prices + Origin Effective Surplus Model stl_phase_b_generated.txt

After partner loop completes for each origin state:

// Add origin's OWN production to wavg sums wavg_psum += own_production × own_price wavg_wsum += own_production // Production-weighted market price market_price = wavg_psum / wavg_wsum // Full effective surplus full_eff = max(own_buy, own_sell) × (market_price − own_price) / market_price // MARGINAL surplus: subtract existing trade from last month // Only the delta is passed to Phase C — system walks toward optimum if full_eff > 0: eff_export = max(0, full_eff − last_export) if full_eff < 0: eff_import = max(0, |full_eff| − last_import) // If marginal ≤ 0: already at/past optimum → nothing written

Outputs (stored per state per good)

stl_was_$g stl_wad_$g stl_max_was_$g stl_max_wad_$g stl_market_price_$g stl_eff_export_$g stl_eff_import_$g

Orchestrated by stl_gravity_calculation.txt — batches 8 states/day × 13 days = 104 state capacity.

Phase C: Trade Amounts + Apply Modifiers Days 21–28

C0: Clear Old Modifiers Model stl_phase_c_effects.txt

Removes previous month's export/import/transport modifiers from all depots. Old values stay active until this point.

Sub-pass 3d: Exporters

Export Trade Amount Model

// Guard: eff_export > 0 AND max_WAD > 0 trade = min(eff_export, max_WAD / 100) // EMA: always 80/20 (new routes: 0.2 × signal) trade = 0.2 × trade + 0.8 × old_export // Rate cap: max 50% increase/cycle (floor 5) trade = min(trade, old + max(old × 0.5, 5)) // Decay: if signal gone, 80%/cycle until < 0.5

eff_export is MARGINAL. Triple dampening: marginal + EMA + rate cap.

Sub-pass 3d: Importers

Import Trade Amount Model

// Guard: eff_import > 0 AND max_WAS > 0 trade = eff_import // EMA: always 80/20 (new routes: 0.2 × signal) trade = 0.2 × trade + 0.8 × old_import // Rate cap: max 50% increase/cycle (floor 5) trade = min(trade, old + max(old × 0.5, 5)) // Decay: if signal gone, 80%/cycle until < 0.5

Same triple dampening as exports. Conservation normalization balances total I/E.

Sub-pass 3d.5

Conservation Normalization Model

Scales the larger side (imports or exports) down to match the smaller side. Ensures sum(exports) = sum(imports) market-wide.

Sub-pass 3d.75

Transport Cost (Importers) Model

cost_factor = clamp(max_WAS / WAS, 1, 10) // Pure distance penalty: 100 / avg_proximity // Close sources → ~1, distant → up to 10 transport_amount = import_volume × cost_factor
Sub-pass 3e

Access % (GUI Display) Model

export_access = last_export / eff_export × 100 import_access = last_import / eff_import × 100

Final Outputs (applied to Trade Depot buildings)

stl_export_$GOODS$ modifier stl_import_$GOODS$ modifier stl_transport_$GOODS$ modifier stl_last_export_$GOODS$ stl_last_import_$GOODS$ stl_access_pct_*
Tooltip System (On-Demand, Display Only)

Triggered on hover. Runs its own Bellman-Ford and computes effective_surplus per partner. Does NOT affect the model or depot modifiers. Reads stl_market_price_$GOODS$ from Phase B.

Import Tooltip Tooltip stl_tooltip_effects.txt

stl_build_import_display

  • Runs BF from depot state
  • For each partner: computes source_price, economy_scale, effective_surplus
  • Filter: eff_surp > 0 (cheap partners that can supply)
  • WV = eff_surp × proximity
  • Second pass: contribution %, qty, production-weighted avg price

Export Tooltip Tooltip stl_tooltip_effects.txt

stl_build_export_display

  • Runs BF from depot state
  • For each partner: computes source_price, economy_scale, effective_surplus
  • Filter: eff_surp < 0 (expensive partners that want imports)
  • WV = |eff_surp| × proximity
  • Second pass: contribution %, qty, production-weighted avg price

Reads from Model

stl_market_price_$GOODS$ stl_last_export_$GOODS$

Both tooltips compute their own BF distances (transient, cleaned up after). The effective_surplus computation mirrors Phase B exactly, using the same formula and the stored market_price. Display variables (stl_display_*) are stored on partner states for the GUI to read.

Key Formula Summary
Market Price (production-weighted network average): market_price = Σ(productioni × local_pricei) / Σ(productioni) // summed over all reachable partners + self // sharei = productioni / total_production (implicit) Local Price (per state): local_price = BASE × (1 + 0.75 × clamp((buy − sell) / min(buy, sell), ±1)) // Consumption affects price via buy/sell ratio only Effective Surplus (per partner, relative to origin's market_price): eff_surp = max(buy, sell) × (market_price − source_price) / market_price // Positive: partner is cheap (should export) → WAS // Negative: partner is expensive (should import) → WAD Origin Marginal Surplus (incremental trade signal): full_eff = max(own_buy, own_sell) × (market_price − own_price) / market_price eff_export = max(0, full_eff − last_export) // only the delta from current trade eff_import = max(0, |full_eff| − last_import) // System walks toward revenue-maximizing volume incrementally Gravity Weighting: WAS = Σ(eff_surp × proximity_weight) // proximity = 100 - bf_dist WAD = Σ(|eff_surp| × proximity_weight) Transport Cost (pure distance factor): cost_factor = max_WAS / WAS = 100 / avg_proximity // clamped [1, 10]
